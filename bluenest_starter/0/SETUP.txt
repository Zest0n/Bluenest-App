1) Copy lib/ (replace your main.dart) and assets/ into your Flutter project root.
2) In pubspec.yaml, under the existing `flutter:` section add:

flutter:
  uses-material-design: true
  assets:
    - assets/images/

3) Run:
   flutter pub add http flutter_secure_storage
   flutter pub get
4) Android: in android/app/src/main/AndroidManifest.xml add inside <manifest>:
   <uses-permission android:name="android.permission.INTERNET"/>
   and on <application ...> add:  android:usesCleartextTraffic="true"   (needed for http:// during dev)
   flutter_secure_storage needs minSdkVersion 23 in android/app/build.gradle(.kts)
5) flutter run
